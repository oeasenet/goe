# Goe Documentation

Welcome to the developer documentation for **Goe**, a modular Go application framework built on top of Uber's Fx and GoFiber. This documentation is split into several focused guides that show how to configure, extend and run applications with Goe.

## Contents

- [Getting Started](getting-started.md)
- [Configuration](configuration.md)
- [HTTP Module](http.md)
- [Cache Module](cache.md)
- [Database Module](database.md)
- [Examples](examples.md)
- [Best Practices](best-practices.md)

Each guide can be read independently, but they work best when read in order. For a quick walkthrough of building a small project, start with [Getting Started](getting-started.md).
